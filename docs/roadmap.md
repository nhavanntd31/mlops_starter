# Lộ trình Triển khai MLOps

## Kế hoạch 3 tháng
| Tháng | Trọng tâm |
|-------|-----------|
| 1 | Dữ liệu + Training |
| 2 | Serving + CI/CD |
| 3 | Monitoring + Governance |

## Sổ đăng ký Rủi ro
| Rủi ro | Tác động | Giảm thiểu |
|--------|----------|-----------|
| Suy giảm chất lượng dữ liệu | Cao | Validation tự động |
| Hiệu suất model giảm | Cao | Quality gates, rollback |

## Chỉ số thành công
- R² >= 0.60
- Độ trễ API p95 < 200ms
- Phát hiện drift trong 24 giờ
